## 📂 Projects

### 🥫 European Packaged Food Market Analysis &nbsp;*(Bootcamp Capstone)*
End-to-end pipeline analyzing ~70,000 packaged food products across 10 European countries from the Open Food Facts dataset. Built with DuckDB/Parquet ingestion, a 4-table MySQL schema, an XGBoost Nutri-Score classifier (85.6% accuracy), Tableau dashboards, and a Streamlit prediction app.
Key finding: GDP per capita has essentially no relationship with a country's average Nutri-Score grade.

`Python` `DuckDB` `MySQL` `XGBoost` `Tableau` `Streamlit`
[💻 Code](https://github.com/Kanak2208/european-food-market-analysis) · [📊 Live Dashboard](https://public.tableau.com/app/profile/kanak.yadav2046/viz/EuropeanFoodMarketAnalysis/HOME)

### 🔬 Vanguard A/B Hypothesis Testing
End-to-end analysis of a real-world A/B experiment on Vanguard's digital onboarding interface (50,500 users). Includes funnel analysis, three formal hypothesis tests (Z-test, T-test, Mann-Whitney U), and an interactive Tableau dashboard.
Result: the new UI lifted completion rate by +3.71 pp (p < 0.05), and the error rate at the Confirm step dropped from 37.84% to 11.29%.

`Python` `SQL` `Tableau` `Hypothesis Testing` `A/B Testing`
